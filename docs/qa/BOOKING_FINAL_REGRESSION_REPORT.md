## A. Production Build

### Root cause

The previous `yarn build` failure (`PageNotFoundError` for nearly every route, including `/_not-found` and `/favicon.ico`) was **not** a broken `service/[[...segments]]` page.

It was caused by a **corrupted / contended `.next` directory** while `yarn build` ran concurrently with an active `yarn dev` process sharing the same `.next` output. That matches the earlier “build succeeded before” observation and the mass ENOENT module errors.

### Exact fix

1. Stopped **only** the Home Healers dev listener on port **3001** (port **3000** left alone).  
2. Deleted this project’s generated `.next` folder.  
3. Ran `yarn build` with no concurrent dev writer.  

**No application source changes were required for the build recovery.**
